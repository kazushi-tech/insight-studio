# Discovery Hub 分析品質レビュー & 改善計画

## Context

saurusjapan.com（スポーツサプリメントブランド）を対象にDiscovery Hubで競合LP分析を実行した結果を、広告運用プロフェッショナルの視点から品質評価する。目的は、分析の考察精度・類推レベル・実用性を判定し、品質向上のための具体的改善策を策定すること。

**分析結果概要**: 検索クエリ「スポーツサプリメント販売」→ 12件候補 → 5サイト分析（SAURUS, MonotaRO, Arches Global, アミノバイタル, Kentai）→ Claude生成CROレポート（2分23秒）

---

## 1. 総合評価

| 評価項目 | 評点 | 判定 |
|----------|------|------|
| **競合選定の妥当性** | 2/5 | 致命的問題あり |
| **LP種別判定の精度** | 5/5 | 極めて正確 |
| **個別プロファイリングの深さ** | 4/5 | 良好 |
| **スコアリングの一貫性** | 3/5 | 改善余地あり |

| **レポート完全性** | 2/5 | 後半セクション切れ |

**総合**: **2.8/5** — 分析エンジンの「考察力」自体は高いが、**入力段階（競合選定）の致命的ミス**がレポート全体の価値を大きく毀損している。

## 2. 致命的問題: 競合選定の精度 (Critical)

### 2-1. 選定された5サイトの妥当性判定

| ブランド | 業種 | SAURUS の直接競合か | 判定 |
|----------|------|---------------------|------|
| **SAURUS** | スポーツサプリメント D2C | — (自社) | — |
| **MonotaRO** | 法人向け総合EC（工具・産業用品） | **NO** | 不適切 |
| **Arches Global** | 海外市場進出コンサルティング | **NO** | 完全に的外れ |
| **アミノバイタル（味の素）** | スポーツサプリメント ブランド | **YES** | 適切 |
| **Kentai（健康体力研究所）** | スポーツサプリメント ブランド | **YES** | 適切 |

**ミス率: 50%**（4社中2社が的外れ）

### 2-2. なぜ MonotaRO が選ばれたか

MonotaROは75.5万点の工業用品を扱う総合ECサイトで、スポーツサプリメントはその中の一カテゴリに過ぎない。検索クエリ「スポーツサプリメント販売」に対してMonotaROのカテゴリページがヒットし、candidate_rankerが以下のように加点した:

- base: 50
- title あり: +10
- snippet あり: +10
- industry keyword 「サプリメント」マッチ: +20
- **合計: 90**（高スコア）

**問題の根本原因**: `candidate_ranker.py` のindustryキーワードマッチが「タイトルorスニペットに業種キーワードが含まれるか」しか見ていない。MonotaROのような総合ECは全カテゴリでキーワードマッチするため、常に高スコアを得てしまう。

### 2-3. なぜ Arches Global が選ばれたか

Arches Globalは「タイ健康食品市場攻略」という記事を公開しているコンサルティング会社。検索で「スポーツサプリメント」「健康食品」に部分マッチし、snippetに「市場」「比較」等のキーワードを含んでいたため高スコアを得た。

**問題の根本原因**: コンサル/メディアサイトを検出するロジックが存在しない。

### 2-4. 選ばれるべきだった真の競合

| ブランド | なぜ競合か |
|----------|-----------|
| **DNS（ディーエヌエス）** | 国産スポーツサプリ最大手、アスリート向けD2C |
| **VALX（バルクス）** | 山本義徳監修、D2Cサプリ急成長ブランド |
| **ビーレジェンド** | コスパ重視プロテイン/サプリD2C |
| **マイプロテイン** | グローバルスポーツ栄養ブランド、日本展開積極的 |
| **ゴールドジム** | ジム系サプリメントライン |
| **ウイダー/inゼリー（森永）** | 大手食品メーカー系スポーツ栄養 |

これらは全て「スポーツをする人に向けてサプリメントを直接販売している」ブランドであり、SAURUSと同じ顧客を奪い合う存在。広告運用者が本当に比較したいのはこれらのLP設計。

## 3. 高評価ポイント: 分析エンジンの考察力

### 3-1. LP種別判定が極めて正確 (5/5)

全サイトのLP種別を正しく判定しており、判定根拠も明確:

- SAURUS → 「コーポレートサイト兼ブランドサイト」: H1がブランドミッション、Hero CopyがSHOPのみ → **正確**
- MonotaRO → 「ECサイト（商品ポータル）」: カテゴリ型ページ → **正確**
- Arches Global → 「コーポレートサイト（記事型リード獲得LP）」: BtoB記事LP → **正確**
- アミノバイタル → 「商品ポータル（ブランドサイト型）」: 製品ポータル → **正確**
- Kentai → 「コーポレートサイト」: パイオニアブランドの老舗サイト → **正確**

プロンプト設計の「LP種別を識別せよ」という指示が効果的に機能している。

### 3-2. SAURUS自体の分析は実務レベルで有用 (4/5)

| 分析項目 | 内容 | プロ判定 |
|----------|------|---------|
| ターゲット仮説 | ランニング・マラソン競技者、20〜40代男性 | 妥当。「AMINO LOADINGでレースを制覇」から正しく推定 |
| ポジション仮説 | 科学的根拠・国産品質のプレミアム | 妥当。「最先端の国産原料」から適切に読み取り |
| 価格戦略 | 【本文推定】中〜高価格帯 | やや浅い。実際は5,000〜8,000円台で明確にプレミアム帯 |
| FV訴求力: 2 | H1がミッション、購買意欲を直接刺激しない | **的確**。広告LP基準では致命的 |
| CTA設計: 1 | SHOPのみ、複数段階のCTA設計なし | **的確**。コーポレートサイトなので当然だが指摘は正しい |
| 最優先改善 | FV直下にCTA+価格を明示し購買導線を確立 | **実務で即実行可能な提案** |

### 3-3. 【本文推定】ラベルの適切な運用

プロンプトの「取得不可を弱みの根拠にするな」「推定には根拠を明示」が正しく機能しており、価格情報など取得不可データを本文から補完する際に【本文推定】ラベルを付けている。広告運用のレポートとして信頼性を保つ良い設計。

### 3-4. 比較結論3行の洞察力

> アミノバイタルが信頼要素・製品ラインナップ・FAQ設計で頭一つ抜けており、商品ポータルとしての完成度は業界最高水準。SAURUSはブランドストーリーの独自性が際立つが、購買導線・価格提示・CTA設計が未整備で広告費用対効果を大きく損なっている。

この2文は広告運用プロとして見ても**的確な洞察**。ただし3文目の「KontaiとSAURUS」は「Kentai」の表記揺れ（AI生成ミス）。

## 4. 改善が必要な問題点

### 4-1. レポート後半セクションの欠落 (Critical)

スクリーンショットにはSection 1（総合サマリー）とSection 2（個別プロファイリング）のみが確認でき、以下のセクションが見当たらない:

- **Section 3: 競合比較テーブル** — 観点別の横断比較
- **Section 4: コンバージョン設計分析** — CV導線・ホワイトスペース
- **Section 5: アクション提案** — 優先度別の具体的改善施策

**原因**: `max_output_tokens=5120` が5サイト分析には不足。日本語テキストはトークン効率が英語より低く、5サイトの詳細プロファイリングだけで4,000トークン近くを消費し、後半セクションが生成される前にトークン上限に達している可能性が高い。

**影響**: 広告運用者にとって最も価値が高いのはSection 5の「具体的アクション提案」であり、これが欠落しているとレポートの実務価値が半減する。

### 4-2. スコアリングの異種基準問題 (Major)

| サイト | 信頼要素スコア | 根拠 | 問題 |
|--------|-------------|------|------|
| MonotaRO | 4/5 | 「人気ランキング」「売れ筋」「当日出荷・送料無料」 | EC全般の信頼要素 |
| SAURUS | 3/5 | 「薬剤師・医師・管理栄養士」専門家監修 | D2Cブランドの信頼要素 |

同じ「信頼要素」軸で採点しているが、EC的な信頼要素（物流・ランキング）とD2C的な信頼要素（専門家エビデンス）は質的に異なる。MonotaROの「ランキング」は単なるEC機能であり、スポーツサプリメント領域の「信頼」とは無関係。

### 4-3. モバイル最適化スコアの推定限界

全サイトのモバイル最適化スコアが「推定」ベースで、実際のモバイルレンダリングを確認していない。レスポンシブデザインの有無、タップターゲットのサイズ、スクロール深度等はHTML抽出だけでは判定困難。このスコアの信頼度は他の軸より低いことを明示すべき。

### 4-4. アミノバイタルのスコアリングが甘い可能性

アミノバイタルのLP効果スコアが軒並み4/5と高評価だが、商品ポータル型サイトに対して広告LP基準の高評価を付けている。プロンプトでは「コーポレートサイトにLP基準で高評価を付けない」と指示しているが、「商品ポータル」が例外扱いされている可能性がある。

## 5. 改善計画

### Phase A: 即時修正（レポート完全性の回復）

#### A-1. トークン予算の増加
- **対象ファイル**: [analyzer.py:229](tmp_market_lens_ai_repo/web/app/analyzer.py#L229)
- **変更**: multi-URL分析時の `max_output_tokens` を 5120 → 12288 に増加
- **理由**: Section 3-5が生成される前にトークン上限到達している
- **影響**: 生成時間+10〜20秒、API コスト約2倍（出力トークン分）、しかしレポート完全性は必須

```python
# 変更前
return await _call_text_model(prompt, ..., max_output_tokens=5120)

# 変更後（single vs multi で分岐）
token_budget = 5120 if len(extracted_list) == 1 else 12288
return await _call_text_model(prompt, ..., max_output_tokens=token_budget)
```

### Phase B: 競合選定品質の向上（最重要改善）

#### B-1. 非競合ドメインブロックリストの拡張
- **対象ファイル**: [candidate_ranker.py:11-16](tmp_market_lens_ai_repo/web/app/services/discovery/candidate_ranker.py#L11-L16)
- **変更**: 総合ECサイト・メディア・コンサル系ドメインをブロックリストに追加
- **追加ドメイン例**: `monotaro.com`, `askul.co.jp`, `yodobashi.com`, `prtimes.jp`, `nikkei.com` 等

#### B-2. 非競合シグナルキーワードの追加
- **対象ファイル**: [candidate_ranker.py](tmp_market_lens_ai_repo/web/app/services/discovery/candidate_ranker.py) 新規ロジック
- **変更**: タイトル/スニペットに「コンサルティング」「市場調査」「レポート」「まとめ」等が含まれる場合 -15点

#### B-3. 業種キーワードマッチの精緻化
- **対象ファイル**: [candidate_ranker.py:104-109](tmp_market_lens_ai_repo/web/app/services/discovery/candidate_ranker.py#L104-L109)
- **変更**: タイトルマッチ=+20 / スニペットのみマッチ=+8 に分離。さらに総合EC特有パターン（「総合通販」「法人向け」「業務用」）を検出して -10

#### B-4. 検索クエリテンプレートの改善
- **対象ファイル**: [keyword_extractor.py:80-81](tmp_market_lens_ai_repo/web/app/services/discovery/keyword_extractor.py#L80-L81)
- **変更**: `"{industry} 競合サイト 比較"` → `"{industry} ブランド 公式サイト"` / `"{industry} 専門 通販"`
- **理由**: 「比較」「ランキング」を含むクエリはメディア記事やEC一覧を呼び込みやすい

#### B-5. URL パス解析による記事ページペナルティ
- **対象ファイル**: [candidate_ranker.py](tmp_market_lens_ai_repo/web/app/services/discovery/candidate_ranker.py) 新規ロジック
- **変更**: `/blog/`, `/news/`, `/column/`, `/article/` パスに -10点
- **理由**: 競合ブランドのホームページではなく記事ページが選ばれるケースを抑制

### Phase C: スコアリング品質の向上

#### C-1. 異種サイト間のスコアキャリブレーション指示
- **対象ファイル**: [analyzer.py:120-135](tmp_market_lens_ai_repo/web/app/analyzer.py#L120-L135) プロンプト内
- **変更**: 「重要な注意事項」セクションに以下を追加:
  - 異なるLP種別のスコアは直接比較不可であることの明記指示
  - 各スコアに「(D2C基準)」「(EC基準)」等の基準タグ付けを要求

#### C-2. モバイル最適化スコアの信頼度表記
- **対象ファイル**: [analyzer.py](tmp_market_lens_ai_repo/web/app/analyzer.py) プロンプト内
- **変更**: モバイル最適化スコアに「※推定ベース」の注記を要求

### Phase D: 高度な改善（オプション）

#### D-1. LLMベースの候補バリデーション
- **対象ファイル**: [candidate_ranker.py](tmp_market_lens_ai_repo/web/app/services/discovery/candidate_ranker.py) + [discovery_pipeline.py](tmp_market_lens_ai_repo/web/app/services/discovery/discovery_pipeline.py)

- **レイテンシ影響**: +3〜5秒
- **効果**: MonotaRO/Arches Global級の誤選定をほぼ完全に排除

#### D-2. 複数検索クエリの並列実行
- **対象ファイル**: [discovery_pipeline.py](tmp_market_lens_ai_repo/web/app/services/discovery/discovery_pipeline.py)
- **変更**: 現在は `queries[0]` のみ使用 → top 2クエリを実行し結果をマージ
- **レイテンシ影響**: +5〜10秒

## 7. 検証方法

### 改善前後の比較テスト

同一URL（saurusjapan.com）で改善前後のレポートを比較:

1. **競合選定**: DNS, VALX, ビーレジェンド, アミノバイタル, Kentai のうち最低3社が含まれるか
2. **レポート完全性**: Section 1〜5が全て生成されているか
3. **スコアリング一貫性**: 異なるLP種別間のスコアに基準タグが付いているか
4. **アクション提案**: 具体的コピー案・CTA文言案が含まれているか

### 追加テストURL

- `valx.jp` — D2Cサプリブランド（競合としてDNS, SAURUS等が見つかるべき）
- `myprotein.jp` — グローバルブランド（日本の競合が見つかるべき）
- `freee.co.jp` — 異業種（会計ソフト）での動作確認

### 既存テストの更新

- `tests/test_candidate_ranker.py` — 新しいペナルティ/ボーナスのテストケース追加
- `tests/test_keyword_extractor.py` — クエリテンプレート変更の反映
- `tests/test_analyzer.py` — トークン予算テスト（`test_multi_url_passes_5120_max_tokens` の期待値を12288に変更）

**非対象**:

---

## 結論

今回の Compare レポートは、前段階より明確に改善している。  
ただし、まだ **提出品質の完成版** とは言えない。

主な理由は次の4点。

1. **比較主体の定義がまだ不正確**
2. **L5文言を起点にした訴求提案がまだ強すぎる**
3. **スコアリングが擬似精密で、根拠の透明性が不足**
4. **実行プランが途中で切れており、最重要セクションが未完**

---

## 現状評価

### 到達点

- `L1 / L2 / L3 / L5` の信頼要素階層を意識できている
- `ブランドサイト vs 獲得型EC` を分けて見られている
- SAURUS の論点が `世界観は強い / 獲得LPは弱い` に整理されている
- WINZONE の勝ち筋が `認証 / 価格 / 定期便` に収束している
- LP改善と検索広告を分ける方向性は正しい

### まだ不足している点

- Compare 対象の `control / competitor / reference` の定義がまだ揺れている
- SAURUS のアンチドーピング訴求が、証拠強度より強く書かれている箇所がある
- `26/40` `44/60` のような数値が、読者に過剰な確からしさを与える
- 一番重要な Section 5 が未完で終わっている

---

## 修正方針

### Task A. 比較主体の taxonomy を固定する

Compare は必ず次の3区分だけを使うこと。

- `入力ブランド（control）`
- `実競合比較対象`
- `参考観測枠`

**禁止事項**

- SAURUS と WINZONE を並べて両方とも `入力ブランド` と書く
- `入力ブランド数: 3` のような誤カウントを出す
- `競合2社のうち主比較は SAURUS・WINZONE` のように control を競合側へ混ぜる

**必須表記**

- 入力ブランド数: 1
- 実競合比較対象数: N
- 参考観測数: N
- 比較対象総数: 1 + N + N

---

### Task B. L5起点の訴求提案をさらに厳格化する

現状レポートでは、L5止まりの `ANTI DOPING` から

- `アンチドーピング対応`
- `対応プロテイン`
- `WADA禁止物質検査済み（確認後）`

のような提案に寄りすぎている。

**修正ルール**

- L5 only の場合は `関連情報の記載あり` まで
- `対応` `認証` `検査済み` `安心して使える` は禁止
- LP改善案でも、L1確認前のコピー例を作らない

**許容表現**

- `アンチドーピング関連情報の掲載有無を確認`
- `競技者向け品質訴求の余地あり`
- `認証取得が確認できれば主要訴求へ昇格可能`

---

### Task C. スコアリングを縮小する

現状の `サイト完成度 / 広告受け皿 / 総合スコア` は、読みやすい一方で擬似精密になっている。

**修正方針**

- 数値スコアは原則廃止、または `High / Mid / Low` の3段階へ圧縮
- 数値を残すなら rubric を脚注で明示する
- `評価保留` があるブランドに総合点を出さない

**推奨代替**

- `獲得対応力`
- `信頼訴求強度`
- `購買導線整備度`

の3軸だけを `高 / 中 / 低` で示す

---

### Task D. CTA評価を `main_cta` 単独依存から外す

WINZONE は `main_cta = お問合せはこちら` でも、実際には商品カード・ランキング・定期便導線が存在しうる。  
ここを `CTA明確性 △` に寄せると、獲得型ECの実態を取り逃がす。

**修正ルール**

- CTA評価は `main_cta` 単独ではなく、以下の合算で判定する
  - 商品カードの購入導線
  - ランキング導線
  - 定期便導線
  - カテゴリLPへの遷移

**評価基準**

- `主CTAが弱くても、購買導線群が強ければ CTA明確性は ○ まで許容`

---

### Task E. 実行プランの完結性を最優先で担保する

今回の最大の実害はここ。  
`5-2. 検索広告施策` が途中で切れており、レポートの価値を大きく落としている。

**必須対応**

- Section 5 は常に最後まで閉じる
- 途中で token 逼迫した場合は Section 4 を圧縮してでも Section 5 を完結させる
- `最優先3施策` → `LP改善` → `検索広告` の順で死守
- Meta / Display は削ってもよいが、検索広告施策は未完禁止

**validator 追加条件**

- `5-2. 検索広告施策` の表が閉じていない場合は fail
- 最終行が `|` で終わらない table row の場合は fail
- `最優先3施策` の後に `5-1` だけで終わっていたら fail

---

### Task F. 実務の広告運用粒度を1段深くする

現状の実行プランは方向性としては良いが、運用に落とす粒度がまだ浅い。

**検索広告では最低限ここまで出す**

- `指名防衛`
- `カテゴリ非指名`
- `比較検討`

それぞれに対して

- 推奨クエリ例
- 除外したいクエリ例
- 着地先
- 主KPI

をセットで出す。

**例**

- 指名防衛: `SAURUS プロテイン`
- カテゴリ非指名: `ランナー プロテイン`
- 比較検討: `マラソン サプリ おすすめ`

---

## Claude への明示指示

以下をプロンプトに強制すること。

1. `入力ブランド = 1社` を絶対に崩さない  
2. `L5 only` から `対応 / 認証 / 検査済み` を書かない  
3. 総合点を出すなら rubric を併記、なければ `高 / 中 / 低` に置換  
4. `CTA明確性` は `main_cta` 単独で判定しない  
5. `5-2. 検索広告施策` は未完終了を禁止  
6. token が厳しい場合は Section 4 を縮め、Section 5 を完結させる

以下を満たしたら完了。

- control / competitor / reference の区分ミスがない
- `入力ブランド数` が正しく 1 になっている
- SAURUS のアンチドーピング訴求が L5相当のまま適切に抑制されている
- WINZONE の CTA評価が導線群ベースで記述されている
- Section 5 が最後まで閉じている
- 検索広告施策が `指名 / 非指名 / 比較検討` の3分類で記述されている

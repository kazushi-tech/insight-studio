# Plan: Discovery Hub 出力品質レビュー — スポーツサプリ比較（SAURUS / Glico / WINZONE / MPN）

## Context

ユーザー提示の Discovery Hub レポート

- SAURUS
- Glico パワープロダクション
- WINZONE
- MPN

を、広告運用プロフェッショナル視点で再評価した。

前回の水回り比較より、**広告運用に使える形へかなり前進している**。
ただし、**高水準の競合分析レポートとして提出できる水準にはまだ届いていない**。

最大の理由は:

1. **分析対象と発見LP一覧の整合性に疑義がある**
2. **「評価保留」と数値スコアの共存が曖昧**
3. **広告アクションの一部が根拠より先に走っている**
4. **競合セットがまだ薄く、一般化しづらい**

---

## 総評

### 判定

- **考察の精度**: 中の上
- **分析の質**: 実務二稿レベル
- **類推の水準**: 以前より改善したが、まだ高水準とは言い切れない

### 良い点

1. **広告運用に必要な形へかなり寄った**
   - 総合サマリー
   - 勝ち訴求 / 避ける訴求
   - 推奨検索クエリ意図
   - 推奨着地先
   - 7日 / 30日施策
   が揃っており、前回より圧倒的に使いやすい。

2. **WINZONE と MPN の勝ち筋整理はかなり良い**
   - WINZONE: 製薬会社品質 × 第三者認証 × 定期便価格
   - MPN: 水で美味しい × 国産 × 送料無料条件
   は、検索広告でもLPでもそのまま使いやすい整理。

3. **Glico を安易に断定していない**
   - `【評価保留】` を付けたのは改善。
   - データが薄い大手ブランドサイトに対して、以前ほど乱暴な断定になっていない。

4. **ブランドサイトと専門店ECの差を前回より分けて見られている**
   - SAURUS と Glico は「売る場」ではなく「ブランド/情報ハブ」に近い
   - WINZONE と MPN は購入CVに近い
   という理解は妥当。

---

## まだ弱い点

### 1. 分析対象と発見LP一覧が一致していない

レポート本文では:

- SAURUS
- Glico
- WINZONE
- MPN

を比較している一方、末尾の `発見されたLP` には:

- Glico
- WINZONE
- MPN
- UP ATHLETE

が出ている。

この状態だと、読み手は次を判断できない:

- SAURUS は入力ブランドで競合一覧には出していないのか
- SAURUS を分析しているが一覧表示だけ漏れているのか
- UP ATHLETE を発見したが分析対象から落としたのか

**この不整合はレポート全体の信頼を大きく毀損する。**

### 2. `評価保留` とスコア付けがまだ衝突している

Glico は `28/80【評価保留】` となっているが、これは読み手にとって中途半端。

- 保留なら比較ランキングから外す
- 数値を出すなら、暫定値・信頼区分を別表示する

のどちらかに寄せるべき。

今の表現だと、
**「比較に入れていいのか悪いのか」が分からない。**

### 3. 類推が根拠より一歩先に出ている箇所がある

例えば:

- `競合唯一の明示`
- `認証バッジ最強`
- `本文中段に埋もれている`
- `到達率低い`

などは、4サイト比較かつ取得データ制約下では強すぎる表現。

正しくは:

- `今回比較した4サイト内では最も強い`
- `取得データ上、上部固定は未確認`
- `ナビ深部の可能性`

程度に抑えるべき。

### 4. 競合セットがまだ少ない

今回の4サイト比較は前回より良いが、広告運用で意思決定するにはまだ薄い。

特に今回の内訳は:

- ブランドサイト: SAURUS, Glico
- 専門店EC: WINZONE, MPN

であり、**直販競争の比較軸が2サイトに偏っている**。

検索広告の訴求差・価格差・CV導線差を見るなら、
最低でも:

- 直競合EC 3〜5
- 準競合 1〜2
- ベンチマーク 1〜2

は欲しい。

### 5. アクションの期待効果がまだやや雑

例:

- `CVR+15%推定`
- `離脱率-20%推定`

は、現状だと説得力の土台が弱い。

必要なのは:

- どの変更が
- どのファネル段階に効き
- どの程度のレンジで見積るか

の説明。

今のままだと、**数字が「それっぽい」止まり**。

## 実務目線の評価

### かなり良くなった点

- `何を広告文に使うか`
- `どこに流すか`
- `どこが弱いか`

が以前より早く読める。

特に WINZONE / MPN については、
広告アカウントの訴求設計にそのまま転用しやすい。

### まだ高水準ではない理由

高水準と言うには、少なくとも以下が必要:

- 分析対象と発見結果の整合性が100%取れている
- 評価保留サイトがランキングに混ざらない
- 類推の強さが証拠強度と一致している
- 競合セットが広告市場を代表できる厚みを持つ
- 推奨アクションに根拠トレースがある

現状はそこまで届いていない。

---

## 改善方針

### 1. `入力ブランド / 発見競合 / 実際の分析対象` を分離表示する

最低でもレポート冒頭で:

- 入力ブランド
- 発見競合候補
- 実分析対象
- 除外された候補

を分けて出す。

### 2. `評価保留` サイトを比較表の別枠へ退避する

Glico のようなケースは:

- 主比較テーブルから外す
- `参考観測枠`

へ移すべき。

### 3. アクション提案に根拠トレースを付ける

各施策に:

- 根拠フィールド
  - hero_copy
  - pricing
  - promo_claims
  - image_alts
  - contact_paths
- 証拠強度

を紐付ける。

### 4. 競合の層を3分類する

- **直競合**
- **準競合**
- **ベンチマーク**

この分類なしに 4〜6社並べるだけだと、広告施策の優先順位を誤る。

### 5. スポーツサプリ業界専用の広告観点を固定化する

今回の業界では少なくとも以下を毎回見るべき:

- アンチドーピング / 認証
- 国産 / GMP / 製薬会社信頼
- 味 / 飲みやすさ
- 価格 / 定期便 / 送料
- レビュー / アスリート使用実績
- 一般層向けか競技者向けか

## 受け入れ基準

1. 発見LP一覧と分析対象ブランドの不整合がなくなる
2. `評価保留` ブランドは主比較表から除外される
3. WINZONE / MPN のようなEC系勝ち筋が、広告文に転用できる粒度で出る
4. SAURUS / Glico のようなブランド・カタログ系は、無理にEC基準で低く採点しない
5. 施策ごとに「なぜそう言えるか」が追える

今回のレポートは、**前回より明確に改善しており、広告運用の叩き台としてはかなり使える**。

ただし、**高水準の分析と言うにはまだ未完成**。

特に:

- ブランド整合性
- 評価保留の扱い
- 類推の強さ
- 競合セットの厚み

の4点は、まだ改善余地が大きい。

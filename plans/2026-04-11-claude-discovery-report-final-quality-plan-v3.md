# Plan: Claude向け Discovery レポート最終品質仕上げ v3

**作成日**: 2026-04-11  
**対象**:
- Discovery Hub の競合発見レポート品質
- Claude の考察精度 / 類推節度 / 実務運用解像度

**非対象**:
- Discovery のシステムエラー
- Compare の表示不具合
- 候補抽出アルゴリズムそのものの変更

---

## 結論

今回の Discovery レポートは、前回までよりかなり良い。  
ただし、まだ **提出品質の完成版** ではない。

主な理由は次の5点。

1. `発見候補` と `実分析対象` の区別がまだ甘い  
2. `L5 only` 情報から作る施策コピーがまだ強すぎる  
3. `価格未取得` なのに価格前提の改善案を出している  
4. `予算配分比率` が実測前としては精密すぎる  
5. 一部の証拠強度ラベルが事実と推論を混ぜている  

---

## 現状評価

### 到達点

- 競合セットはかなり自然になった
- SAURUS / WINZONE / MPN の役割差が読みやすい
- `L1 / L3 / L5` の使い分けは前進している
- 実行プランが最後まで閉じており、前回より実務で使いやすい

### まだ高水準でない理由

- 実測データなしで予算比率や訴求強度をやや断定気味に出している

## 修正方針

### Task A. `発見候補` と `実分析対象` を明示的に分離する

Discovery は Compare と違い、末尾に `発見されたLP` が出る。  
このため、本文で分析した競合と、発見だけして除外した競合が混ざると読者が混乱する。

**必須表示**

- 入力ブランド
- 発見競合候補数
- 実分析対象数
- 参考観測数
- 除外候補数

**必須表現**

- `発見された競合候補`
- `今回の実分析対象`
- `参考観測枠`
- `今回未分析`

**今回の具体論点**

- `UP ATHLETE` は発見されているが本文分析対象に入っていない  
- これを本文中で明示しないと、Glico を選んだ理由が弱く見える

---

### Task B. L5 only から広告コピーを作らない

今回の SAURUS は、

- `ANTI DOPING` のナビ文言確認
- 認証機関名未確認
- 認証番号未確認

の状態。

それにもかかわらず、施策では

- `アンチドーピング情報`
- `アンチドーピング対応`
- `公式ランナーサプリ・アンチドーピング対応`

まで踏み込んでいる。

**禁止事項**

- L5 only を `対応` と書く
- L5 only を `安心して使える` と書く
- L5 only を広告見出し案に直接入れる

**許容表現**

- `競技者向け品質情報の掲載有無を確認`
- `アンチドーピング関連情報の記載あり（内容未確認）`
- `L1確認後に主要訴求へ昇格`

---

### Task C. `価格未取得` ブランドに価格コピー案を出さない

今回の SAURUS は `pricing取得不可` なのに、

- `価格帯・CTAを追加`
- `¥〇〇〜`

という提案が出ている。

これは運用者には便利でも、根拠のない placeholder に見える。

**修正ルール**

- 価格未取得ブランドには `価格コピー例` を書かない
- 先にやるべきは `shopドメインから価格取得` の確認
- 価格未取得時は `商品カテゴリ / ベネフィット / CTA` までに留める

**許容表現**

- `商品カテゴリ・購入CTAを明示`
- `価格情報の取得可否を先に確認`

---

### Task D. 予算配分は固定比率でなく phase 設計にする

現在の

- `指名防衛70 / 非指名30`
- `非指名60 / 比較検討40`

は、実務上の方向性としては分かるが、実測前としてはやや強い。

**修正方針**

- 比率固定ではなく phase で出す
- 初期配分 → 学習後見直し、の形にする

**推奨フォーマット**

- Phase 1: 指名防衛中心
- Phase 2: 非指名テスト拡大
- Phase 3: CPA / CVR 実測後に再配分

**どうしても比率を出す場合**

- `目安`
- `初期仮説`
- `実測後に再配分前提`

を必ず明記

---

### Task E. 証拠強度ラベルをさらに厳密化する

今回は全体として改善しているが、まだ細部で混線がある。

例:

- `main_cta=お問い合わせ` は **確認済み**
- そこから `購買導線が弱い` は **推定**

この2つを同じ文に混ぜると、証拠強度がぼやける。

**修正ルール**

- 事実と解釈を1文で混ぜない
- 1文目で確認済み事実
- 2文目でその解釈

**理想形**

- `【確認済み】main_cta は「お問い合わせ」`
- `【推定】そのため、非指名獲得流入では購買遷移率が下がる可能性`

---

### Task F. WINZONE と MPN の勝ち筋を検索意図でさらに分離する

今回の整理は悪くないが、まだ少し粗い。

**より実務的な分け方**

- WINZONE:
  - 競技者
  - マラソン
  - 認証重視
  - 品質重視
- MPN:
  - コスパ
  - 飲みやすさ
  - 一般運動層
  - 初回購入のしやすさ

**Claude に求めること**

- `誰に強いか` をクエリ意図で1段深く切る
- `競技者向け` と `一般運動層向け` を混ぜない

---

### Task G. SAURUS の改善優先順位を再整理する

現在の最優先施策は方向性として正しい。  
ただし順番はもう少し厳密にしたい。

**理想順**

1. shopドメインの価格 / 商品情報 / 導線確認
2. 専用獲得LPの必要性判定
3. 指名防衛キャンペーン整備
4. 非指名カテゴリテスト着手

現状は 1 を飛ばして 2 に入り気味。

**Claude に求めること**

- `確認すべきこと`
- `作るべきもの`
- `配信すること`

の順に並べる

---

## Claude への明示指示

1. `発見候補` と `実分析対象` を必ず分けて書く  
2. `UP ATHLETE` のような未分析候補は本文で除外理由を明示する  
3. `L5 only` から `対応 / 認証 / 安心` の広告コピーを作らない  
4. `価格未取得` ブランドには `¥〇〇〜` のような仮コピーを出さない  
5. 予算配分は fixed ratio より phase 設計を優先する  
6. 事実と推定を同一文で混ぜず、証拠強度を分離する  
7. WINZONE と MPN は検索意図の強さを別セグメントで書き分ける

## 完了条件

以下を満たしたら完了。

- 発見候補 / 実分析対象 / 参考観測 / 未分析候補が明確に分かれている
- SAURUS のアンチドーピング訴求が L5 相当のまま適切に抑制されている
- SAURUS の価格訴求が未取得前提のまま無理に書かれていない
- 予算配分が phase 設計または仮説レンジで示されている
- WINZONE / MPN の勝ち筋が検索意図ベースでより具体化されている
- 施策表の証拠強度が、確認済み事実と推定を分離して記述されている

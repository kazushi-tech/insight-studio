# Plan: Discovery Hub 出力品質レビュー — 水回りCRO比較（Hits / パパサラダ / SANEI）

## Context

ユーザー提示の Discovery Hub レポート

- Hits Online Shop
- パパサラダ
- SANEI

の3サイト比較について、広告運用プロフェッショナル視点でレビューした。

2026-04-10 時点で各実サイトも確認したうえでの結論は、**叩き台としては使えるが、高水準の分析レポートにはまだ届いていない**。

特に問題なのは:

1. **パパサラダの読み落としが大きい**
2. **サイト種別の違いを同じ物差しで点数化している**
3. **「評価不能」と「弱い」を混同している**
4. **広告運用の意思決定に必要な粒度まで落ちていない**

---

## 総評

### 判定

- **考察の精度**: 中程度。Hits は比較的良いが、パパサラダで大きく落としている
- **分析の質**: 実務初稿としては成立。ただし「比較可能性」の設計が甘い
- **類推の水準**: 高水準ではない。証拠強度の管理と広告アクションへの接続が不足

### 良い点

1. **見るべき論点自体は大きく外していない**
   - FV訴求力
   - CTA設計
   - 信頼構築
   - ベネフィット訴求
   - 価格心理学
   - CV導線設計
   は、CRO観点として妥当。

2. **Hits の主問題抽出はおおむね正しい**
   - FV が休業告知で占有されている
   - 正規代理店としての権威性は強い
   - 見積・問い合わせはあるが、FVで勝ち筋が前に出ていない
   この整理は広告運用上も有効。

3. **SANEI をメーカー公式ブランドサイトとして扱った方向性は正しい**
   - 直販ECと同列ではない
   - ブランド訴求と商品閲覧導線はある
   という理解は妥当。

### 弱い点

1. **パパサラダの事実把握が不足**
   - 現行レポートは「ログイン優先」「データ不足」を主軸に置いているが、実サイトには以下の明確なシグナルがある:
   - お問い合わせ導線
   - ご利用ガイド
   - FAQ
   - 売れ筋ランキング
   - 最大45%割引訴求
   - 法人向け大口注文・見積り
   - 送料無料導線
   - 「開業から13年の実績」
   - 国内在庫品は1〜3日で発送予定
   - 在庫限り・数量限定系の訴求
   このサイトを「参考程度」で処理すると、分析の土台が崩れる。

2. **サイト役割の違いをスコアに吸収できていない**
   - Hits は販売寄りEC
   - パパサラダは専門店EC
   - SANEI はメーカー兼ブランド・サポート導線
   この3者を同一の `総合スコア(/60)` で並べると、比較の意味が曖昧になる。

3. **未知と低評価の区別が不十分**
   - 価格未取得
   - 本文取得不足
   - 画像由来訴求の抽出漏れ
   があるときに、実質的に低スコア化している箇所がある。
   これは「サイトが弱い」のではなく「抽出が弱い」可能性を見落としている。

4. **広告運用への接続が浅い**
   - このレポートだけでは
     - どの検索意図に何を当てるか
     - どの訴求で広告文を組むか
     - どのLPに流すべきか
     - どの施策を7日以内/30日以内で分けるか
   が十分に判断できない。

## 実サイト確認による補正

### Hits Online Shop

- **レポートの評価は概ね妥当**
- 2026-04-10 時点で、実際にトップで休業告知が強く見えており、FV機会損失の指摘は正しい
- 一方で、ヘッダーには
  - ログイン
  - 新規会員登録
  - 見積もり依頼BOX
  - お問い合わせ
  があり、CTA設計はゼロではない
- 正規代理店根拠も明確に存在するため、**「信頼は強いが、勝ち訴求が前面化できていないEC」** という整理が適切

### パパサラダ

- **このレポートで最も精度が低い**
- 実サイト上には:
  - 売れ筋トップ10
  - 「最大45%割引」
  - お問い合わせ
  - ご利用ガイド
  - FAQ
  - 法人向け大口注文・見積り
  - 送料無料商品導線
  - 「開業から13年の実績」
  - WaterMark認証品
  - 1〜3日発送予定
  - 在庫限り
  が確認できる
- したがって、現行レポートの
  - 信頼構築 3
  - CTA設計 3
  - CV導線設計 3
  は低すぎる可能性が高い
- **正しくは「画像・販促バナー由来の訴求を取りこぼした結果、過小評価している」** と見るべき

### SANEI

- **方向性は正しいが、弱く言い過ぎている箇所がある**
- 実サイトには
  - DESIGN PRODUCT 導線
  - 商品カテゴリ導線
  - おすすめ商品
  - FAQ
  - お問い合わせ
  - カタログダウンロード
  - ワンクリックで見積書ダウンロード可能な外部導線
  がある
- そのため、`CV導線設計 = 3` は低めに出しすぎ
- ただし、**「直販購入導線が弱い」** という指摘自体は正しい
- よって、正しい整理は **「購入CVは弱いが、中間CVとサポートCVは一定水準ある」**

## 根本課題

### 1. 画像・バナー・alt起点の販促訴求を拾えていない

水回りECは、テキスト本文よりも:

- 画像バナー
- ランキング見出し
- 特集画像
- キャンペーン画像
- お問い合わせ/見積りバナー

に重要な訴求が埋まっていることが多い。

ここを落とすと、パパサラダのようなサイトを誤診する。

### 2. 「サイト完成度」と「広告受けLP適性」が混ざっている

SANEI はメーカーサイトとしては悪くないが、広告LP受けとしては弱い。
この2つを1つの総合点にまとめると、改善優先度がぼける。

### 3. ホームページ比較とLP比較が混在している

今回見ているのは純LPではなく、各社トップページ寄り。

- ホームページとしての導線評価
- 広告着地先としての評価

は別で出すべき。

### 4. 証拠強度に対して断定がやや強い

特に `データ不足` のサイトに対して、低スコアや弱い断定をそのまま置くのは危険。

---

## 改善方針

### 1. 比較軸を二層化する

現行の `総合スコア` をやめ、少なくとも次の2軸に分ける:

- **サイト完成度スコア**
  - 情報設計
  - 信頼
  - 商品探索性
  - サポート導線
- **広告受け皿スコア**
  - FV訴求
  - オファー明確性
  - CTAの近さ
  - 比較検討不安の解消

これで SANEI のようなメーカーサイトを不当に低く評価せずに済む。

### 2. サイト種別ごとに配点を変える

最低でも以下に分岐:

- 正規代理店EC
- 専門店EC
- メーカー/ブランドサイト
- サポート/カタログ主導サイト

同じ `CTA設計` でも、求めるゴールは違う。

### 3. 抽出品質ゲートを強化する

以下を満たせない場合は、低スコアではなく `評価保留` を優先する:

- body text 十分量
- 主要CTA抽出
- 価格/割引/納期の抽出
- 信頼要素抽出
- 画像alt/バナー見出し抽出

### 4. 広告運用レイヤーを追加する

レポートに必須で追加:

- **勝ち訴求**
- **負け訴求**
- **推奨クエリ意図**
- **推奨着地先**
- **7日以内施策**
- **30日以内施策**

### 5. 水回り業界専用の観点を明示する

一般CROではなく、このカテゴリでは少なくとも以下を固定観点に入れる:

- 正規品/代理店保証
- 施工可否/適合確認
- 納期/在庫
- 法人見積/大口発注
- デザイン性
- メンテナンス/交換部材
- FAQ/問い合わせの強さ

## 受け入れ基準

1. パパサラダが「データ不足のため参考扱い」にならず、ECとしての販促訴求を正しく拾える
2. SANEI が「購入導線は弱いが、中間CV導線はある」と表現される
3. Hits が「信頼は強いがFV勝ち訴求が弱い」と整理される
4. `評価保留` と `低評価` が混同されない
5. レポート最下部を読めば、広告運用者が
   - 何を訴求するか
   - どこに流すか
   - 何をテストするか
   を即判断できる

## 最終判断

今回のレポートは、**方向性は良いが、高水準の分析として提出するには未完成**。

特にパパサラダの読み落としは、広告運用者がそのまま意思決定に使うには危険。

次に目指すべきは:

- 抽出精度の改善
- サイト種別別の評価
- 不確実性管理
- 広告運用アクションへの接続

の4点。

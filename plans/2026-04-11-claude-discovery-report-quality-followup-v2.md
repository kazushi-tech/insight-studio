# Plan: Claude向け Discovery レポート品質フォローアップ v2

**作成日**: 2026-04-11  
**対象**: Discovery Hub のレポート品質改善  
**非対象**: LP比較分析のエラー対応、品質ゲート失敗時の復旧制御、UIエラー表示  

---

## この plan の目的

今回の Discovery レポートは、前回よりかなり改善している。

特に良くなった点:

- 競合セットがスポーツサプリ業界らしくなった
- `確認済み / 評価保留` の扱いが前より自然になった
- `L1〜L5` の信頼要素 taxonomy を導入し始めた
- 媒体 / KPI / ファネルまで施策案が降りてきた

一方で、**広告運用の高水準レポート**としてはまだ未完成。

今回 Claude にやってもらうべきことは、エラー対応ではない。  
やるべきは、**レポート本文の考察精度・表現の節度・広告運用解像度を上げること**。

---

## 現在の評価

### 判定

- **考察の精度**: 中の上
- **分析の質**: 実務三稿手前
- **類推の水準**: 改善したが、まだ高水準とは言えない

### この出力で良い点

1. **競合選定がかなり妥当になった**
   - WINZONE
   - MPN
   - Glico
   という並びは、前回よりはるかに実務向き。

2. **広告運用者が見たい論点に寄ってきた**
   - 非指名獲得か
   - 指名流入向きか
   - どの訴求で勝つか
   - どの媒体で出すか
   が読める。

3. **証拠強度の扱いが前より改善**
   - SAURUS の `ANTI DOPING` を、少なくとも `L5 ナビ文言` として扱い始めたのは前進。

### まだ高水準ではない理由

1. **事実と推奨施策の距離がまだ遠い**
   - SAURUS で確認済みなのは `ANTI DOPING` という文言レベルなのに、
     エグゼクティブサマリーや施策で `アンチドーピング認証` へ寄せてしまう箇所が残る。

2. **比較対象の数え方がまだ曖昧**
   - タイトルは `競合3社`
   - 本文では `今回比較4サイト中`
   - 主比較は3社、ただし SAURUS も比較表に入る
   という構造で、読み手が一瞬迷う。

3. **施策テーブルの設計が少し混線している**
   - `LP改善` の行にも `媒体=Google検索` が入っており、
     施策の種類（LP改修 / 広告配信 / クリエイティブ改善）が混ざって見える。

4. **KPIの質にばらつきがある**
   - `LP-CVR / CPA` は実務的
   - 一方で `滞在時間` は、獲得施策の補助KPIとしては弱い

5. **終盤の圧縮設計がまだ弱い**
   - 今回の出力もアクションプラン終盤で切れている
   - これはエラー処理以前に、Claude に渡す出力契約の密度がまだ重い

## Claude にやってほしい改善

### 1. `認証` と `言及` を厳密に分ける

現在の課題:

- `ANTI DOPING` の文言確認
- 認証取得済み
- 検査体制あり

が、やや近い扱いになっている。

Claude には以下を厳守させる。

- `第三者認証 confirmed`
- `自社品質主張 confirmed`
- `外部実績 confirmed`
- `文言存在 only`

を明確に分ける。

禁止:

- `文言存在 only` から `認証取得済み` を言うこと
- `認証未確認` なのに広告コピーで断定表現を作ること

### 2. 比較スコープの表現を固定する

今回の出力は実質:

- `自社 1`
- `競合 3`
- `参考観測 1`

のような構造なのに、本文の数え方が揺れる。

Claude には冒頭で必ず次を出させる。

- 入力ブランド
- 実競合比較対象数
- 参考観測数
- 比較対象総数

例:

- `本レポートは SAURUS を含む4サイト比較です。競合3社のうち、主比較対象は WINZONE / MPN、Glico は参考観測です。`

### 3. 施策レイヤーを分離する

今のアクション表は以下が混ざっている。

- LP改修
- 検索広告運用
- Meta配信
- クリエイティブ転用

Claude には施策を次の3層で出させる。

- **LP改善**
- **検索広告施策**
- **Meta/ディスプレイ施策**

これにより、`媒体` が不要な施策に無理に媒体列を付けない。

### 4. KPI を媒体別に最適化する

Claude には媒体別に以下を基準化させる。

#### 検索広告

- 主KPI:
  - LP-CVR
  - CPA
  - Impression Share（指名）
- 補助KPI:
  - CTR
  - CPC
  - Search term fit

#### Meta / ディスプレイ

- 主KPI:
  - LPV
  - ViewContent率
  - AddToCart率
- 補助KPI:
  - CTR
  - CPC
  - エンゲージ率

禁止:

- 獲得施策の補助KPIに `滞在時間` を安易に置くこと

### 5. 推奨着地先を「改修後TOP」に逃がさない

今回の SAURUS では:

- ブランドTOP（改修後）

へ寄せているが、非指名獲得においては雑。

Claude には、着地先を次の3択で明示させる。

- ブランドTOP
- 商品カテゴリLP
- 専用獲得LP

特に非指名獲得は、原則 `専用獲得LP` または `カテゴリLP` を優先。

### 6. ブランド別評価を短く・鋭くする

終盤で切れやすいので、ブランド別評価は以下に圧縮する。

- 要約1文
- 強み2点
- 弱み2点
- 評価テーブル

長い修辞は減らし、根拠の列挙は最小限にする。

### 7. アクションは `上位3件` に絞る

今のように8件以上並べると、重要度の低い施策まで出て終盤が切れる。

Claude には以下の形にする。

- **最優先 3施策**
- 必要なら `補足施策（任意）`

これでレポートの芯を太くする。

## 新しい出力契約

Claude に渡す出力契約は、以下の順に固定する。

### 1. エグゼクティブサマリー

- 検索意図別の勝ち筋
- 獲得向き / 指名向き
- クライアント向け最優先1施策

### 2. 分析対象と比較前提

- 入力ブランド
- 競合3社
- 参考観測の扱い
- 比較対象総数

### 3. 競合比較サマリー

- 主比較テーブル
- 競合の勝ち筋 / 負け筋を1行で

### 4. ブランド別評価

- 各ブランドを短く鋭く
- `認証 / 言及 / 実績 / UGC` の違いを保ったまま記述

### 5. 実行プラン

以下の順に分ける:

1. LP改善
2. 検索広告
3. Meta/ディスプレイ

各セクションで上位3施策まで。

## Claude への具体指示

Claude に渡す際は、少なくとも以下を明示する。

1. `ANTI DOPING` のような文言存在は `認証` と書かないこと
2. `競合3社` と `比較4サイト` のような数え方のズレをなくすこと
3. 施策を `LP改善 / 検索広告 / Meta` に分離すること
4. 非指名獲得の着地先は `ブランドTOP改修後` ではなく `カテゴリLP or 専用獲得LP` を優先すること
5. ブランド別評価を圧縮し、アクションは上位3件に絞ること
6. 獲得施策の補助KPIに `滞在時間` を安易に置かないこと

---

## 受け入れ基準

1. SAURUS の `ANTI DOPING` が `認証取得済み` と誤読されない
2. 比較対象の総数と競合数が本文で一貫する
3. `LP改善` と `広告運用` が同じ表で混線しない
4. 非指名獲得の着地先が `専用獲得LP / 商品カテゴリLP` ベースで提案される
5. KPI が媒体に応じて実務的になる
6. 終盤で切れにくい分量に圧縮される
7. 施策の優先順位が上位3件で明確になる

---

## 最終判断

今回の Discovery レポートは、**叩き台としてはかなり使える水準**まで来ている。

ただし、まだ `広告代理店提出レベルの高水準レポート` ではない。

次に Claude にやらせるべきことは、
大きな構造変更ではなく、

- 証拠強度の節度
- 比較スコープ表現の一貫性
- 施策レイヤーの分離
- KPIの実務化
- 出力量の圧縮

この5点の仕上げである。

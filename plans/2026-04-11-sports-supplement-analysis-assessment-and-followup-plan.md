# Plan: スポーツサプリ比較レポート評価と改善フォローアップ

**作成日**: 2026-04-11  
**対象**:
- `LP比較・競合分析レポート`（SAURUS / Glico / WINZONE）
- `Discovery Hub レポート`（SAURUS / アミノバイタル / ザバス / HALEO）

---

## Context

ユーザー提示の2本のレポートを、広告運用プロフェッショナル視点で再評価した。

結論として、**ページ観察の精度は上がっているが、広告運用の意思決定資料としてはまだ高水準とは言えない**。

特に問題なのは、個別LPの読みはそれなりに良い一方で、

1. 競合母集団の設計が2レポートで揺れている
2. 事実と類推の境界がまだ甘い
3. 広告運用に必要な「市場・クエリ・オファー・計測」まで落ちていない
4. レポート品質の基本整合性に崩れが残っている

の4点。

## 総評

### 判定

- **考察の精度**: 中の上
- **分析の質**: 実務二稿レベル
- **類推の水準**: 中程度。高水準とはまだ言い切れない

### 良い点

1. **サイト種別の切り分けは妥当**
   - SAURUS をブランドサイト
   - WINZONE / HALEO を獲得型EC
   と見る整理は、広告運用上かなり重要で、ここは改善している。

2. **勝ち訴求の抽出は実務転用しやすい**
   - WINZONE の `製薬会社品質 × 第三者認証 × 定期便`
   - HALEO の `価格・送料・レビュー`
   - SAURUS の `ランナー特化 × ブランド世界観`
   は、検索広告やLP見出しに転用しやすい。

3. **SAURUS の課題認識は概ね正しい**
   - 購買CTA不足
   - 価格露出不足
   - 社会的証明の弱さ
   は、ブランド流入後の取りこぼし要因として自然な指摘。

4. **Glico を主比較から外す判断は前進**
   - タグページや情報ポータルを、無理に獲得LPと同列採点しない姿勢は正しい。

## まだ弱い点

### 1. 競合セットがレポート間で揺れている

1本目では:

- SAURUS
- Glico
- WINZONE

2本目では:

- SAURUS
- アミノバイタル
- ザバス
- HALEO

が主比較になっている。

これはそれぞれ単体ではあり得る組み方だが、**なぜその集合になったのかが読み手に説明されていない**。

そのため、

- 本当に最重要の直競合は誰なのか
- 価格比較の土俵は誰と誰なのか
- ブランド育成の比較は誰と誰なのか

が曖昧なままになる。

### 2. 類推が証拠より先に走る箇所が残っている

以下は典型例:

- ナビ項目から認証取得状況まで踏み込む
- コミュニティ名からターゲット階層を断定気味に書く
- LP上の露出順が不完全取得なのに `埋もれている` と表現する
- ベースラインなしに `CTR改善余地あり` `CVR改善余地あり` と置く

方向性は分かるが、**高水準レポートなら表現を一段弱めるか、保留に落とすべき**。

### 3. 広告運用の分析としてはまだCRO寄り

現状のレポートは、

- CTAはあるか
- 価格は見えるか
- 信頼要素はあるか

というLP診断にはなっている。

一方で、広告運用の意思決定に必要な以下がまだ薄い。

- どの検索意図を取りにいくのか
- どの訴求は検索広告向きで、どの訴求はMeta向きか
- どのLPを非指名獲得に使うべきで、どれは指名防衛に留めるべきか
- 価格・定期便・送料・初回条件がCPAにどう影響しそうか
- 計測でどのKPIを持つべきか

つまり、**LP読解としては進歩しているが、広告運用設計としてはまだ一段浅い**。

### 4. レポートとしての整合性に基本的な傷がある

今回の提示内容だけでも、少なくとも以下が見える。

- `実行日時` は 2026-04-11 03:20:53 UTC なのに `作成日` が `2025年`
- アクションプランの末尾が `製薬会社品質」訴` で途切れている
- `確認済み` と `推定` の運用は改善したが、なお断定調が残る

この種の崩れは、内容以前に**提出物としての信頼性を削る**。

## 広告運用者としての評価

### 使える部分

- SAURUS のブランド訴求は強いが、獲得LPとしては弱い
- WINZONE / HALEO 系は非指名獲得の受け皿に向く
- アミノバイタル / ザバスは情報探索から比較検討の橋渡しに使える

この3点は、実務でも十分に使える。

### そのまま予算判断に使うには危ない部分

- 競合母集団が固定されていない
- 価格/送料/定期便の比較がブランド横断で不揃い
- 効果予測にレンジと条件がない
- `誰に何をどの面で見せるか` が媒体別にまだ浅い

よって、**現状は「良い叩き台」ではあるが、「高水準の完成分析」ではない**。

---

## 改善方針

### 1. 競合母集団を先に固定する

比較対象は毎回次の3層に分ける。

- **直競合EC**: 非指名獲得で直接ぶつかる
- **直競合ブランド**: 指名・ブランド想起でぶつかる
- **ベンチマーク**: LP設計や訴求だけ参考にする

これを冒頭に明示しない限り、結論が毎回ぶれる。

### 2. 事実・類推・保留の表現ルールをさらに厳格化する

必須ルール:

- HTML / 画像alt / visible text で取れたものだけを `確認済み`
- 導線や対象者像の解釈は `推定`
- 順位・到達率・改善率はデータ不足なら `評価保留`

また、`最も強い` のような比較表現には必ず

- `今回比較したXサイト内では`

を付ける。

### 3. LP診断だけでなく広告運用設計へ広げる

各ブランドについて最低限次を出す。

- 主戦場クエリ
- 勝てる訴求
- 負けやすい訴求
- 推奨媒体
- 推奨着地先
- 初回テストのKPI

これがないと、レポートは運用会議で止まる。

### 4. スポーツサプリ専用の評価軸を固定化する

毎回見るべき観点:

- アンチドーピング / 第三者認証
- 製造信頼性（製薬会社, GMP, 国内製造）
- 味 / 飲みやすさ / 継続しやすさ
- 価格帯 / 1回あたり単価 / 定期便
- 送料 / 送料無料条件
- レビュー件数 / 使用者属性 / アスリート実績
- 初心者向けか競技者向けか

### 5. 効果予測は固定値ではなくレンジで出す

例:

- `CVR改善余地: 小 / 中 / 大`
- `優先度: 指名防衛 / 非指名獲得 / リマーケ`
- `期待インパクト: 1-2週間では学習、4-8週間で評価`

現時点の材料で `CVR+15%` のような数字を出すのは危険。

### 6. レポート品質の最低契約を設ける

最低でも以下を必須化する。

- 日付矛盾なし
- 見出し欠損なし
- 末尾欠けなし
- 分析対象と発見候補の整合あり
- `評価保留` を主ランキングに混ぜない

## 新しいプラン

### Task A: 競合セット再設計

内容:

- 入力ブランド
- 発見候補
- 実分析対象
- 除外候補
- 競合層分類

を冒頭で固定表示する。

完了条件:

- 2本のレポートで主比較対象が変わる場合、理由が明記される

### Task B: 広告運用レイヤー追加

内容:

各ブランドごとに、

- 指名向きか
- 非指名向きか
- 比較検討向きか
- リマーケ向きか

を明示し、さらに

- 推奨媒体
- 推奨訴求
- 推奨着地先
- 初回KPI

をセットで出す。

完了条件:

- LP診断で終わらず、実運用に移せる

### Task C: 類推表現の抑制

内容:

- `唯一`
- `最強`
- `到達率が低い`
- `埋もれている`

のような強い表現を、証拠強度に応じて制限する。

完了条件:

- 類推の強さが証拠強度と一致する

### Task D: スポーツサプリ専用テンプレート強化

内容:

- 競技者向け
- 一般運動層向け
- ボディメイク向け
- マラソン / 持久系向け

の切り分けを出力に反映する。

完了条件:

- 同じ `スポーツサプリ` でも誰向けの訴求かが明確になる

### Task E: 効果予測をレンジ化

内容:

- 固定の改善率表現をやめる
- 優先度 / 効果レンジ / 検証指標に置き換える

完了条件:

- 予測が誇張ではなく仮説として読める

### Task F: 出力品質ゲート追加

内容:

- 日付整合
- セクション完結
- 末尾欠け検知
- 主比較と参考観測の分離

を出力前に検査する。

完了条件:

- `2025年` と `2026-04-11` のような矛盾や途中切れが残らない

---

## 受け入れ基準

1. レポートを見ただけで、競合集合の作り方が分かる
2. SAURUS / WINZONE / HALEO / アミノバイタル / ザバス などの位置づけがぶれずに説明される
3. `確認済み` と `推定` の使い分けが一貫する
4. 広告運用アクションに `媒体・訴求・着地先・KPI` が揃う
5. 効果予測が固定値断定ではなくレンジと条件で出る
6. 日付矛盾や見出し欠損のない提出品質になる

---

## 最終判断

今回の考察は、**以前よりかなりマシで、広告運用の叩き台としては十分使える**。

ただし、**高水準の分析** と呼ぶにはまだ不足がある。

不足しているのは主に:

- 競合母集団設計
- 類推の節度
- 広告運用レイヤー
- 提出品質の安定性

この4点を詰めれば、`よくあるAI要約` から `実務で予算判断に使える資料` に近づく。

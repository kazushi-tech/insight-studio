# Insight Studio 初回有償導入チェックリスト

更新日: 2026-07-10

## 現在販売できる範囲

最初の商品は、不特定多数向けセルフサービスではなく、担当者が1社ずつ接続と初回レポートを確認する「管理された先行導入」とする。

顧客が直接使う範囲:

- Webサイト成果レポート
- 根拠グラフ
- 対象期間と取得状態の確認
- 基本的なAI考察

導入担当者が実行する範囲:

- 競合LP比較
- 競合候補の発見
- バナー・クリエイティブ分析
- AIキー、利用上限、プロバイダー設定

## 受注前

- [ ] 公式お問い合わせフォームで相談を受け取れる
- [ ] 対象サイト数と担当者数を確認した
- [ ] GA4からBigQueryへの出力状況を確認した
- [ ] 見たい成果（問い合わせ・予約・購入など）を確認した
- [ ] 初期設定支援と定例支援の範囲を決めた
- [ ] 料金、提供範囲、AI利用料、解約条件を個別書面に記載した
- [ ] 利用規約、プライバシー、データ取扱いを法務確認した

## セキュリティ

- [ ] 過去に利用したGemini・Anthropicキーを失効した
- [ ] リポジトリ履歴に含まれた旧案件パスワードをすべて再発行した
- [ ] 新しいキーをローカルとRenderの必要なサービスへ設定した
- [ ] 古いキーでリクエストが成功しないことを確認した
- [ ] 顧客案件に固有の `case_id` と `dataset_id` を割り当てた
- [ ] `ADS_CASES_JSON` をRenderのSecretとして投入し、リポジトリ内の台帳へ本番資格情報を置いていない
- [ ] Ads / Market Lensへ同じJWT署名秘密を設定し、旧JWTでは401になる
- [ ] 別案件JWTで対象データセットへアクセスすると403になることを確認した
- [ ] 案件ユーザーが管理者専用APIと高度分析APIを利用できないことを確認した
- [ ] 旧JWTを破棄し、全利用者が再ログインした

## 初回セットアップ

- [ ] 顧客用パスワードを安全な方法で発行・共有した
- [ ] 対象案件だけがログイン後に表示される
- [ ] 最新期間が取得できる
- [ ] アクセス、来訪元、入口ページ、成果の取得状態を確認した
- [ ] 未取得と0件が別の状態として表示される
- [ ] PC、390px、360pxで準備からレポートまで完走した
- [ ] 実資格で「準備→まとめ→グラフ→AIに聞く」を完走した
- [ ] 顧客と一緒に初回レポートを読み、次回確認項目を決めた

## 運用

- [ ] 障害時の連絡先と受付時間を契約書へ記載した
- [ ] Render / Vercel / BigQueryの監視担当を決めた
- [ ] 顧客単位の保存場所一覧と削除手順を記録した
- [ ] 解約時のパスワード停止、データ削除、削除完了連絡の手順を決めた
- [ ] 毎月の利用回数、支援工数、AI利用額を記録する

## セルフサービス販売へ進む条件

- 顧客管理DBと招待・停止・再発行
- 高度分析データの所有者列と全APIの認可
- 顧客コードまたは専用ログインURLによる、全件bcrypt照合を使わない認証
- レポート履歴のサーバー保存、出力、削除
- 課金、プラン権限、解約
- 利用規約、特定商取引法表示、プライバシー表示
- 依存サービスを含む監視と復旧手順

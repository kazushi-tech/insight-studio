# Insight Studio 販売準備チェック

更新日: 2026-07-10

## 提供価値

Insight Studio は、GA4 から BigQuery に出力された Web サイトデータを、初心者にも読みやすいレポート・グラフ・次の確認項目へ変換する。競合・LP・クリエイティブ分析は、必要な利用者だけが Gemini または Claude の API キーを設定して追加する。

## 想定顧客と最初の仕事

- 主な利用者: 自社サイトを持つ中小企業の担当者、営業担当、広告運用担当
- 最初の仕事: 対象サイトと期間を選び、30秒で現状と次の確認先を把握する
- 高度な仕事: 課題が見つかった後に、競合・LP・クリエイティブを追加分析する
- 将来の仕事: 分析で決めた地域・LP・訴求を「とどくくん」の地域広告設定へ引き渡す

## 顧客別パスワード運用の前提

- 「ペタサイト」は自社サイト用の先行案件として扱う。
- 将来は顧客コードまたはメールアドレスとパスワードで、1つの顧客案件だけを認証する。
- 認証トークンへ `case_id` と権限を含め、BigQuery の保存先はブラウザ指定ではなくサーバー側の案件台帳から決定する。
- 顧客ごとにセットアップ条件、生成レポート、履歴、AI利用額を分離する。
- 顧客追加・停止・パスワード再発行は、管理者だけが使える顧客管理機能から実行する。

案件JWTには `role / case_id / dataset_id` を含め、案件ユーザーのBigQuery処理はサーバー案件台帳のデータセットへ固定した。別案件のデータセット指定を403にする負のテストも追加済みである。

案件ユーザーは明示した自案件APIだけを利用でき、それ以外の設定・旧ファイル・Google Drive・デバッグ・高度分析APIは403にした。AI考察も署名済み案件のBigQueryデータへ固定し、任意ファイルや別データソースは処理前に拒否する。

本番の案件台帳は秘密環境変数 `ADS_CASES_JSON` を必須とし、active案件のデータセット重複や同一ハッシュ再利用は起動時に拒否する。リポジトリ履歴に残る旧案件ハッシュは消えないため、販売前に全案件パスワードを再発行する。顧客登録API、JWT個別失効、レポートのサーバー永続保存はセルフサービス販売前の未完了項目である。

## API キーと認証の境界

| 機能 | Gemini / Claude | Google / BigQuery 接続 |
| --- | --- | --- |
| 基本レポート | 不要 | 実データでは必要 |
| グラフ | 不要 | 実データでは必要 |
| 根拠に基づく自動整理 | 不要 | 実データでは必要 |
| 競合・LP分析 | 必要 | 不要 |
| クリエイティブ診断 | 必要 | 不要 |
| 自由文による詳細AI考察 | 必要 | 実データでは必要 |

AIキーはブラウザの永続領域へ保存せず、利用中のタブ内だけで保持する。Market Lensの非同期ジョブにも保存しない。旧ジョブJSONに残っていたキー項目はローカル環境で除去済みだが、過去に使ったGoogle・Anthropicキーは失効・再発行し、本番環境変数も更新する必要がある。

ログアウト時は、分析キーだけでなく案件別レポート履歴、セットアップ、実行途中の下書き、案件情報、端末信頼トークンを削除する。共有端末へ別顧客の内容を残さない。

競合・LP・クリエイティブ分析は、所有者単位のデータ分離が完成するまで管理者だけが実行する。案件ユーザーには機能の存在を表示するが、先行導入中は導入担当者が安全に実行する。

未実装の顧客・プロジェクト作成/招待画面は機能フラグで既定OFFにした。既知脆弱性のある旧Excel解析依存も削除し、顧客Excelアップロードは安全なparserと悪性ファイル試験が揃うまで販売版へ出さない。

## 先行導入の収益モデル

一般向けのセルフサービス課金を先に約束せず、初期は次の順で販売する。

1. 無料デモで画面と接続条件を確認する。
2. セルフ運用プランでは、利用者自身が GA4 / BigQuery と任意の AI キーを管理する。
3. 導入・運用支援では、データ定義、初期接続、見る指標、定例分析手順を有償で整備する。
4. 利用件数、サポート工数、AI利用額を観測してから、月額プランと従量条件を確定する。

公開LPの導入相談先は `VITE_SALES_CONTACT_URL` で上書きできる。未設定時はペタビット株式会社の公式お問い合わせフォームへ遷移する。公開の「画面サンプル」は認証不要で確認でき、顧客用ログインとは分離する。

## 一般販売前の必須ゲート

- [ ] 利用規約、プライバシーポリシー、特定商取引法上の表示を公開する
- [ ] 申込、問い合わせ、契約、請求、解約の実運用を決める
- [x] 案件ユーザーを自案件の基本レポート・グラフ・AI考察APIだけに限定し、全他APIをdeny-by-defaultにする
- [x] AI API キーをブラウザ永続保存からセッション限定利用へ移行し、非同期ジョブへの保存を停止する
- [ ] 過去に利用したGoogle・Anthropicキーを失効・再発行し、Render / Vercel / ローカル環境を更新する
- [ ] GA4 / BigQuery 接続の権限不足、未取得、一部取得、期限切れを画面から復旧できるようにする
- [ ] Render / Vercel の監視、アラート、障害時連絡、バックアップ、復旧手順を整備する
- [ ] Gemini の利用上限を別バックエンド間で一元管理するか、サービス別上限として契約に明記する
- [ ] 実顧客データを使った受入テストと、主要画面の PC / 390px / 360px 回帰テストを自動化する
- [ ] `ADS_CASES_JSON` と両バックエンド共通のJWT署名秘密を本番へ投入し、重複データセットを解消する

- [ ] React Router監査警告を追跡し、安全版公開後に更新する（現SPAは指摘対象のserver/data-router機能を未使用）

## 「とどくくん」連携の準備契約

連携はまだ実装済みとして販売しない。将来連携では、Insight Studio から以下だけを明示的なユーザー操作で渡す。

- 推奨地域と根拠期間
- 対象 LP URL
- 訴求案と確認済み根拠
- 配信前に人が確認すべき注意事項

広告配信の作成・変更は外部状態を変えるため、自動実行せず確認画面を必須にする。

## 現在の販売判定

- 管理された先行導入: コードゲートは Critical 0 / Major 0。キーと案件パスワードのローテーション、本番秘密環境変数、案件ごとの固有データセット、実資格E2Eの確認後に可能
- 不特定多数へのセルフサービス販売: 未達
- 本番リリース: 現時点は BLOCKED。外部キー失効、本番設定、実資格E2E、法務・契約・請求・監視の実施証跡がない
- 判定理由: 分析画面、公開サンプル、公式相談導線、全APIの案件境界、APIキー非保存、ログアウト時データ削除、PC/スマホ表示は整った。高度分析の所有者DB、サーバー履歴、課金、法務、監視運用は残っている
